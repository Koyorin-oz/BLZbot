# 📸 Bannière de la Boutique

## Emplacement

Placez votre image de bannière "LA BOUTIQUE" ici :

```
/workspace/niveau/src/assets/boutique_banner.png
```

## Spécifications recommandées

- **Format** : PNG
- **Largeur recommandée** : 1024px - 1920px
- **Hauteur recommandée** : 200px - 400px
- **Ratio** : 16:9 ou similaire (paysage)
- **Poids** : < 8 MB

## Instructions

1. Enregistrez votre image "LA BOUTIQUE" (fond rouge avec rayures)
2. Nommez-la `boutique_banner.png`
3. Placez-la dans `/workspace/niveau/src/assets/`
4. Redémarrez le bot

## Aperçu de l'affichage

La bannière sera affichée :
- En haut de la commande `/boutique`
- Avant le solde de Starss
- Au-dessus de la liste des items

## Notes

- Si le fichier n'existe pas, la commande fonctionnera quand même sans bannière
- Le fichier doit être accessible en lecture par le bot
- Format PNG recommandé pour la transparence (si nécessaire)
